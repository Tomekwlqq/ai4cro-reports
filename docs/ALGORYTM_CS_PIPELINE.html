CEP — Consumer Entry Points

CEP = sytuacja wejścia do kategorii, nie cecha produktu. Przykład: „depilacja przed wakacjami" = CEP (sytuacja). „bezprzewodowy" = atrybut → NIE CEP.

Gate sytuacja-vs-atrybut: „Czy ten trigger zmieni się gdy zmienię klienta, nie zmieniając kategorii?" Nie zmieni = CEP ✓. Zmieni = atrybut → do KCF, NIE do CEP.
