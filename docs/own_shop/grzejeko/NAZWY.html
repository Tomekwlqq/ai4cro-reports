  • Wymowa i zapis ze słuchu (waga 2): Da się wymówić i zapisać po polsku ze słuchu (telefon, reklama radiowa)? 2 = zero problemów; 1 = jeden problem; 0 = dwa i więcej.   • Niezależność prądowa (waga 3): Czy nazwa niesie niezależność energetyczną (własny prąd, brak zależności od sieci i cen)? 2 = wprost (niezależny, własny, swój, samowystarczalny); 1 = pośrednio (zawsze, pewny, stały, spokój); 0 = brak.
  • Daleko od dużych marek (waga 2): Czy nie jest za blisko Columbus, Enpal, Sonnen, Tesla, Anker, Solix (i innych graczy / programów)? Podobieństwo znaków (difflib) do listy marek. 0 = >=0.75 albo zawiera markę (>=5 znaków); 1 = 0.60–0.75; 2 = poniżej 0.60.
