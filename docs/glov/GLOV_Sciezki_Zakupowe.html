2b. Conversion Index — ranking wejść Shopify lipiec · formuła poniżej

Co to jest: Jeden wskaźnik który mówi czy dana strona wejścia ZARABIA powyżej czy poniżej swojego udziału w ruchu.
Dla kogo: Planowanie mediów — gdzie wysyłać kampanijny ruch żeby nie przepalać.

Conversion Index = (% checkoutów ze strony X) ÷ (% sesji ze strony X)
>1.0 = strona konwertuje lepiej niż jej udział w ruchu sugeruje → warto tu kierować więcej ruchu
= 1.0 = strona konwertuje proporcjonalnie do ruchu → neutralna
<1.0 = strona "pożera" ruch bez proporcjonalnego zwrotu → ograniczaj kampanie tu kierujące
Źródło: Shopify sessions (server-side, bez adblock bias). Liczono jako checkouts/sessions per entry.

3. Ranking ścieżek zakupowych Clarity — purchase sessions

Co to jest: Clarity nagrało sesje które zakończyły się zakupem i pokazało jakie kroki użytkownik przeszedł. To rzeczywiste zachowanie — nie model statystyczny.
Do czego służy: Widzisz dosłownie: "osoba przyszła na kolekcję → kliknęła PDP → dodała do koszyka → kupiła". Możesz optymalizować każdy krok oddzielnie.
Wniosek #1 — IDEALNA ścieżka: Ścieżka B (PDP bezpośrednio → koszyk → zakup). Najkrótsza, CR 2.26%. Osiągasz ją przez: Google CPC/Organic → konkretny produkt PDP. Nie przez kolekcję.
Wniosek #2 — NAJCENNIEJSZA ścieżka: Ścieżka E (HP → zakup). CR 3.47%, AOV 262 PLN. Meta flight_promo → HP to właśnie ta ścieżka — trzymaj ją.
Wniosek #3 — DOMINUJĄCA ale nieefektywna: Ścieżka A (kolekcja → PDP → koszyk) = 39.5% zakupów przy CR zaledwie 1.44%. Masa przepływu, słaba konwersja.
Red flag — Ścieżka D: "Back and forth" (kolekcja ↔ PDP wielokrotnie) = kupujący nie może się zdecydować. Symptom że PDP nie daje wystarczającej pewności zakupu.
