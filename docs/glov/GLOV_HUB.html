Pełna atrybucja Advantage+ — projekt UTM ID-based

Problem: Advantage+ generuje dynamiczne nazwy kreacji → utm_content ≠ ad.name w Meta → 2003 sesji/tydz. bez matchu w GA4 (konwencja nieznana).

Plan (4 kroki):

  1. Meta Ads Manager — URL parameters na poziomie kampanii (nie kreacji): utm_content={{adset.id}}&utm_term={{ad.id}}. Usunąć UTM z URL-ów kreacji. Wszystkie kampanie, w tym Rossmann geo. ~15 min.
  2. merge_3levels.py — dodać ID-based matching w resolve_ga_row() jako primary path (name-based zostaje jako fallback dla historii). ~2h.
  3. Nowy GA4 pull — po wdrożeniu Kroku 1, odpalić rebuild_from_proxy() ze świeżym query 4-wymiarowym. JSON przebuduje się bez re-scraping Meta.
  4. Shopify CAPI (opcjonalne, osobna sesja) — Customer Events → server-side → odzysk ~15–25% zakupów bez UTM w Meta.

Oczekiwany efekt: adset match 28% → ~88% · nieznana 2003 sess/tydz. → <300 · Rossmann geo 0 → 17 adsetów widocznych.
