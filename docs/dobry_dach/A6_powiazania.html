🔗 A6 — powiązania WZ ↔ FV ↔ kasa

Klikalne listy między bazami: każda faktura wie, których wydań dotyczy, a każde wydanie — czy ma fakturę i czy pieniądze wpłynęły. Dane:

Faktury i wydania, których dotyczą

Fakturaklientnettowydań (WZ)wpłatyterminstan

Klik w wiersz faktury rozwija listę wydań (WZ) i wpłat, które ją zamykają. To ta sama struktura, którą METRON ma dostarczyć z bazy: faktury[] → wz[].

Wydania bez faktury — dziury

Wydanie (WZ)klientnettodatastan
Dlaczego tak: dziura to nie „w drodze” — to wydanie, po którym nie ma dokumentu po drugiej stronie. Tu jest lista do zamknięcia, nie statystyka (rozjazd liczby dziur: 1 171 vs 557 vs 1 359 — do uzgodnienia z METRONEM).

Czego potrzebuje ta strona od bazy

Struktura danych (jedna odpowiedź z bazy, bez przetwarzania po drodze):

{ "pomiar": "RRRR-MM-DD",
  "klienci": { "id": "nazwa" },
  "faktury": [ { "fv": "FS …", "klient": "id", "netto": 0.00, "termin": "RRRR-MM-DD",
                 "wz": [ { "nr": "WZ …", "netto": 0.00 } ],
                 "wplaty": [ { "nr": "KP / Bank przyjmie …", "kwota": 0.00, "data": "RRRR-MM-DD" } ] } ],
  "wz_bez_fv": [ { "nr": "WZ …", "klient": "id", "netto": 0.00, "data": "RRRR-MM-DD" } ] }

Ta strona tylko to rysuje — nie liczy i nie zgaduje. Jeśli baza czegoś nie wie (np. brak powiązania), ma to zostać puste pole, nie zero.
