Jak czytać tę mapę

  1. Trzy tabele, trzy rodzaje produktów: Hardware, Software i Aplikacja / System mają różne moduły karty — nie porównuj ich między sobą.
  2. Kolumna = produkt, wiersz = moduł karty. Nad kolumną: zdjęcie, nazwa i pasek „% materiału” (ile z karty mamy gotowe albo w źródłach).
  3. W każdej komórce dwa znaczniki: T = tekst, O = obraz. Kolor mówi, co mamy: zielony — gotowe na karcie, niebieski — pełny materiał w źródle (do przepisania / wycięcia), pomarańczowy — częściowo, szary — brak. Brak znacznika = ten wymiar w module nie występuje.
  4. Kliknij znacznik, żeby przejść do podglądu karty tego produktu, dokładnie do tego modułu. Tam widać sam materiał (zdjęcia, strony ulotki), skąd jest, a puste miejsca są zaznaczone ramką „Brak tekstu / Brak zdjęcia”.
  5. Najedź na znacznik, żeby bez klikania zobaczyć źródło i krótką notatkę.
  6. Kliknij nazwę produktu nad kolumną — otwiera cały podgląd karty.
  7. Na dole: dla każdego produktu link do podglądu karty i lista dokumentów RFB, z których pochodzi materiał.

„Opracowanie NOTEL” = materiał przygotowany przez nas na podstawie dokumentów RFB (np. wycięte z ulotki ujęcia produktu).
