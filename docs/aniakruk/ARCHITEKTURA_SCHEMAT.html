Kręgosłup operacyjny systemu — szkielet, na którym można osadzić dowolny obszar do optymalizacji. Zaczynamy od CRO: UX/UI i funkcjonalności, a później systematycznie możemy dokładać nowe. Każdy element z + klikalny — zobacz realne przykłady.

Setup technicznywspólny · gdzie to mieszka
+
Serwer — VPS Linux + Docker
Mieszka na nim cały mózg: bazy (Postgres/Supabase), silniki, pamięć Honcho. Nigdy nie stoi u klienta — metodologia zostaje po naszej stronie.
+
Orkiestrator — Claude Agent SDK
Headless na serwerze + scheduler (cron/systemd). Odpala agentów bez człowieka przy klawiaturze i dobiera model do zadania.
+
Modele — Claude · Hermes · DeepSeek / OpenRouter · Ollama
Claude API do analiz i strategii, Hermes + DeepSeek / OpenRouter API do prostych zadañ, Ollama z modelem lokalnym do batchu i embeddingów.
+
Konektory — MCP
GA4 przez gotowy serwer MCP, Segmentify przez własny konektor REST. Tylko odczyt, szyfrowane, nic do instalowania u klienta.
Setup wykonawczy — CROmózg u nas · klient nie konfiguruje
Kokpit — Mission Controlwspólny
+
Moduł briefingu
Ustalacie, co system ma monitorować: które ścieżki, które elementy strony i które KPI. To wy mówicie, co jest ważne.
+
Moduł rejestrowania eventów
Rejestr zdarzeń mierzonych w sklepie — co jest śledzone, czy działa poprawnie i czego brakuje, żeby zamknąć obraz ścieżki.
+
Dane live
Liczby klienta zestawione z benchmarkami kategorii i konkurencji w jednym widoku.
+
Analizy obszarowe
Raporty per obszar w ludzkim języku: co, dlaczego, co zrobić.
+
Lista napraw
Wszystkie problemy z audytów w jednym miejscu — priorytet, obszar, status, komentarz.
+
Lista taktyk do testów
Kolejka taktyk zaproponowanych przez system — co testujemy teraz, co czeka.
+
Komunikaty
System sam zgłasza, co wymaga uwagi: anomalie, spadki, szanse.
+
Uruchamianie dowolnych silników wykonawczych
Z kokpitu odpala się analizy i audyty — klikasz i system rusza.
+
Interaktywny asystent
Pytasz językiem naturalnym, odpowiada z Twoich danych. Dyskutuje, nie dyktuje.
