Google Analytics 4

Adres: tomekwlq@proton.me · rola: Edytor (Editor)

pomiar ruchu i sprzedaży na wszystkich wersjach sklepu; Edytor pozwala poprawić konfigurację zdarzeń, bez zmian w kodzie strony

  1. Wejdź na analytics.google.com i wybierz konto Futonlove.
  2. Kliknij Administracja (Admin, koło zębate w lewym dolnym rogu).
  3. W kolumnie Konto wybierz Zarządzanie dostępem do konta (Account access management) — dostęp na poziomie konta obejmie wszystkie usługi, czyli wszystkie wersje sklepu naraz.
  4. Kliknij + → Dodaj użytkowników (Add users).
  5. Wpisz tomekwlq@proton.me i zaznacz rolę Edytor (Editor). Pole „Powiadom nowych użytkowników” może zostać zaznaczone.
  6. Zatwierdź przyciskiem Dodaj (Add).

Dostęp na poziomie konta może nadać tylko Administrator konta. Jeśli każda wersja sklepu ma osobne konto GA4, powtórz kroki dla każdego konta.

Google Tag Manager

Adres: tomekwlq@proton.me · rola: konto: Użytkownik · kontenery: Edycja (Edit)

sprawdzenie i poprawki pomiaru; przy roli Edycja publikacja zmian zostaje po Waszej stronie

  1. Wejdź na tagmanager.google.com.
  2. Przy koncie Futonlove kliknij Administracja (Admin) → Zarządzanie użytkownikami (User Management) w kolumnie Konto.
  3. Kliknij ikonę dodawania + → Dodaj użytkowników (Add users).
  4. Wpisz tomekwlq@proton.me. Uprawnienia konta: Użytkownik (User).
  5. W sekcji kontenerów zaznacz wszystkie kontenery sklepu i ustaw Edycja (Edit).
  6. Kliknij Zaproś (Invite).

Jeśli wolicie zacząć ostrożniej, wystarczy Odczyt (Read) — wtedy poprawki przygotuję jako opis do wdrożenia.

Google Search Console

Adres: tomekwlq@proton.me · rola: Użytkownik z ograniczonym dostępem (Restricted user)

dane wyszukiwania per rynek; uprawnienie tylko do odczytu, ustawienia zostają u agencji SEO

  1. Wejdź na search.google.com/search-console.
  2. Wybierz usługę sklepu (np. futonlove.pl).
  3. W menu po lewej: Ustawienia (Settings) → Użytkownicy i uprawnienia (Users and permissions).
  4. Kliknij Dodaj użytkownika (Add user).
  5. Wpisz tomekwlq@proton.me, uprawnienie Użytkownik z ograniczonym dostępem (Restricted user) i zatwierdź.
  6. Powtórz dla każdej usługi sklepu w Search Console (.pl, .com, .cz, .de, .fr, .nl; .at, gdy ruszy).

Użytkowników może dodać tylko właściciel usługi — jeśli właścicielem jest agencja Rafała, ten krok najszybciej zrobi ona.

Microsoft Clarity

Adres: tomekwlq@proton.me · rola: Admin

mapy kliknięć i nagrania sesji; rola Admin jest potrzebna, żeby wygenerować token do automatycznego pobierania danych

  1. Wejdź na clarity.microsoft.com i otwórz projekt sklepu.
  2. Kliknij Settings → Team.
  3. Kliknij Add team member.
  4. Wpisz tomekwlq@proton.me, wybierz rolę Admin → Add.
  5. Powtórz dla każdego projektu, jeśli każda wersja sklepu ma osobny projekt Clarity.

Token: po nadaniu roli Admin generuję go sam (Settings → Data Export → Generate new API token). Jeśli wolicie nie dawać roli Admin: wygenerujcie token tą ścieżką, nazwijcie go „Tomasz Waligóra”, i prześlijcie SMS-em na 600 401 283, nie mailem. Token służy tylko do odczytu danych.

Google Ads (opcjonalnie)

Adres: tomekwlq@proton.me · rola: Tylko do odczytu (Read only)

zestawienie kampanii ze sprzedażą i zachowaniem na stronie; rola tylko do odczytu nie pozwala niczego zmienić w kampaniach Witolda i Konrada

  1. Wejdź na ads.google.com i wybierz konto Futonlove.
  2. Kliknij Administracja (Admin) → Dostęp i bezpieczeństwo (Access and security).
  3. Na karcie Użytkownicy (Users) kliknij +.
  4. Wpisz tomekwlq@proton.me, poziom dostępu Tylko do odczytu (Read only).
  5. Wyślij zaproszenie — przyjdzie na podany adres, przyjmę je od razu.
  6. Powtórz dla każdego konta reklamowego (Polska i rynki zagraniczne).

Rola tylko do odczytu nie pozwala niczego zmienić w kampaniach.
